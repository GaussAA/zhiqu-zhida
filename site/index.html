Lessons Learned

两个值得讲的坑

LLM 改写 query 反而削弱召回（87.5% → 100%）

百度推出了哪款大模型？ 经 deepagents 被改写为 百度 大模型，距离 0.5298 越过阈值 0.45 而漏召。抓工具日志证伪后，改为「原句 + 改写」双路混合检索，召回恢复且多轮指代不丢。

端口占用致索引未更新（37.5% 假象）

Windows git-bash 下 pkill 杀不掉原生 python 进程，旧 uvicorn 占 8720，新进程未 rebuild_index，对外仍是旧 4 家。改用 netstat + taskkill /F 强杀后复测正常，并沉淀进避坑指南。

Design System

设计即决策

开发者 + 设计师双身份的产物。不堆 AI 默认的「高饱和蓝 + 弥散投影」，而用发丝线、低饱和柔底、清晰留白做出克制而现代的质感。亮 / 暗双主题共用同一套 token，保证跨端一致。

▬

发丝线代投影

用 1px 低不透明度描边（black/8、white/7）建立层级，替代弥散大投影，界面更轻、更「贵」。

◐

低饱和柔底

状态 / 意图 / 命中徽章用 10% 底色 + 对应深色字，信息可读却不抢主视觉。

◑

暗色蓝提亮

暗底强调色用 #60A5FA 而非 #3B82F6，对比度更高、护眼且现代感更强。

AI 默认风
精修后

左：高饱和蓝 + 粗投影；右：发丝线 + 克制留白 → 同一信息，不同质感。
